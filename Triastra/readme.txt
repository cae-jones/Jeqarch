This is a 3D audio adventure game.
The perspective is third person--the camera follows the player, but the angle is fixed.

Currently supported text output includes:
- Microsoft SAPI5
- Jaws for Windows
- Window Eyes
- System Access
- NVDA
- Clipboard (useful for translations)
- Screen reader mode defaults to displaying text in the title bar if no screen reader is detected, or if the necessary libraries are missing (only applies to NVDA and System Access).


=== Basic Controls ===

Arrow keys, or A/S/W/D: Movement.
Shift + left/right, or shift + A/D: Fly quickly left/right. In certain areas, will also rise a little if on the ground.
Shift + up, or shift + W: Fly up.
Shift + down, or shift + S: Fly down.
Spacebar or G: basic attack
Z (tap) : Power up
Tab, shift + tab : select target.
R : Special beacons. Can point to special items, indicate the ends of passageways, etc, depending on context.
X : Get area description
C : Read player coordinates
H : Read health
Y : Read power
Q : Read current quest
Escape: Pause / cancel menus.
Enter: Activate menu item, advance dialog.
Page up / page down: Adjust background music volume
F5 : Voice options (main voice)
Alt F4: exit (warning: game progress is not saved this way!)
Control: Stop speech, if possible.

=== Context-specitif controls ===

Menus: up/down to select, enter to activate, escape to cancel.
- Sometimes, holding shift when activating an item will reverse the effect (for example, increasing rather than decreasing BGM volume).

Dialog: Enter or H to advance, directions to repeat last spoken line, A to skip.
